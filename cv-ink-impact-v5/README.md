# INK / IMPACT V5 — Contrast Studies

CV web editorial de Luis Alberto Sabrera Espinoza, construido a partir del CV profesional proporcionado el 09/10/2026.

- Diseño original inspirado en principios de composición, contraste y ritmo gráfico de Bleach TYBW; no copia materiales de la franquicia.
- HTML semántico, CSS, JavaScript vanilla. Sin frameworks, APIs, tracking ni build.
- Tres escalas de tipografía, retícula fluida, escenas de contraste papel/tinta/carmín/cobalto.
- Secciones: perfil, experiencia, resultados, capacidades, formación y contacto.
- Motion opcional, accesible, con reducción del sistema y control manual.
- Imprimir como PDF desde navegador.

**Contenido:** la experiencia y las cifras provienen del CV adjunto. No se inventaron cargos ni clientes.

**URL prevista, cuando GitHub Pages publique:** https://sabreraluis.github.io/Portafolio/cv-ink-impact-v5/

**Estructura:** `index.html`, `styles.css`, `app.js`, `DESIGN_SYSTEM.md`.

**Privacidad:** el número y email de contacto forman parte del CV público. Si no se desea mostrar alguno, editar `index.html` antes de difundir el sitio.
