**Studios TKOH** aparece en cuarto lugar como experiencia complementaria de UX/UI y CRM SaaS. Existe un enlace secundario, no un CTA principal, al otro portafolio de UX.

## Precisión sobre «comunicación para el desarrollo»

UNICEF define C4D como un proceso basado en evidencia y participación que facilita diálogo y cambio social. La experiencia aportada en el CV demuestra **comunicación institucional y claridad informativa**, pero no documenta una campaña C4D participativa. Por eso la web presenta C4D **como una dirección profesional de crecimiento**, no como una atribución ficticia de casos, instituciones o resultados.

## Tecnología y límites

HTML5/CSS/JavaScript nativos sobre GitHub Pages. No requiere backend, API paga, frameworks, cookies de seguimiento ni permisos externos. Responsive 320–1920 px, SEO básico, navegación por anclas, PDF descargable, modo de movimiento reducido y opt-in voluntario para FX. No emplea retratos generados que aparenten ser el autor ni recursos oficiales de anime.

**QA local:** tests dentro de `qa/`, incluyendo `marketing_positioning.py`, `navigation_quality.py`, `living_fx.py`, `browser_smoke.py`, `cinematic_bridges.py`, `dossier_motion.py`, `production_gate.py`, `static_checks.py` y `resource_budget.py`.

**Pendientes sin afirmar éxito:** Safari/iOS físico, Android físico, fuentes externas en producción y Core Web Vitals públicos; el éxito de GitHub Actions solo confirma el proceso comprobado, no sustituye pruebas manuales.
