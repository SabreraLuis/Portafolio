# V7.8 — Decisiones de posicionamiento y art direction

**No es un portafolio de diseñadora/diseñador UX.** Es la presentación profesional de un comunicador con experiencia transversal.

- **Qué se promete:** marketing comercial y performance; publicidad y branding; comunicación institucional; UX/UI como complemento.
- **Qué se demuestra:** cargos/empresas y resultados documentados en el CV.
- **Qué no se promete:** campañas completas, ONG/proyectos C4D realizados, creatividades originales descargables o resultados no documentados.
- **Comunicación para el desarrollo:** enfoque de interés y proyección profesional, no caso ejecutado acreditado.
- **Arte:** conserva la tensión editorial, corte, manchas negras y movimiento; incorpora un sistema de tres campos profesionales con accesos a evidencia.
- **Prioridad del usuario:** evaluar al profesional integral; no competir con el portafolio de UX que ya existe.
- **Arquitectura:** hero → visión → tres frentes → trayectoria (AMP, 20 Prod., SUNAFIL, TKOH) → resultados → método → formación → contacto / UX secundario.
- **Navegación:** anclas preservadas, menús y encabezado pegajoso, botones «Siguiente» alineados al nuevo orden.
- **Verificación:** pruebas de accesibilidad básica/teclado, movimiento reducido, cambios reales de FX, CSS responsive y consistencia de fuentes.
- **Herramientas:** no se añade backend porque el sitio no maneja datos ni formularios propios.
